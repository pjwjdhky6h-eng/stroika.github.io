# Стройка PWA — комплект для HTTPS-хостинга

`index.html` — исходная рабочая версия v5 с сохранённой структурой и логикой. Объект открывается нажатием на карточку; отдельная кнопка `✎` останавливает всплытие клика и открывает редактирование. Изменения сохраняются в локальном хранилище браузера на устройстве.

## Состав

- `index.html` — приложение, mobile-first размеры касания и безопасные отступы для экранов телефона, подключение установки и service worker.
- `manifest.webmanifest` — имя, режим standalone и пути к иконкам.
- `service-worker.js` — кэш оболочки приложения, переходов и загруженных изображений для работы без сети после первого посещения.
- `icons/` — PNG 192×192, 512×512 и maskable 512×512, включая iOS touch icon.

## Размещение и установка

1. Распакуйте архив и загрузите **содержимое** папки на HTTPS-хостинг в один каталог. Например, если приложение будет по адресу `https://example.com/stroika/`, разместите все файлы именно в `/stroika/`; настройки `start_url` и `scope` относительные.
2. Откройте этот адрес онлайн хотя бы один раз, чтобы браузер установил service worker и заполнил кэш.
3. На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой». На Android используйте «Установить приложение» в меню/приглашении браузера.

Service worker работает только через HTTPS или `localhost`. Фотографии с внешнего Unsplash адреса могут показываться офлайн, если браузер успел закэшировать их при сетевом просмотре; для гарантированного офлайн-режима фотографий их следует хранить в комплекте локально. Данные v5 остаются локальными на каждом устройстве, общей базы между пользователями нет.

Сами функции и поля исходной v5 сохранены. В частности, добавление файлов в v5 сохраняет в приложении имя и размер файла, а не содержимое; это существующее поведение исходника.
