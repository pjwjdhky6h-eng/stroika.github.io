# Стройка PWA — публикация через GitHub Pages

Это готовый статический сайт: сервер и сборка не нужны. GitHub Pages предоставит HTTPS, необходимый для установки PWA.

## Опубликовать

1. Создайте новый публичный репозиторий на GitHub (например, `stroika-pwa`).
2. Загрузите в корень репозитория **всё содержимое этой папки**: `index.html`, `manifest.webmanifest`, `service-worker.js`, папку `icons` и файл `.nojekyll`.
3. Откройте репозиторий → **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. Дождитесь публикации и откройте адрес, показанный в разделе Pages. Для проекта `stroika-pwa` он обычно имеет вид `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/stroika-pwa/`.
6. Откройте адрес онлайн хотя бы один раз. На iPhone: Safari → «Поделиться» → «На экран Домой». На Android: меню браузера → «Установить приложение».

При публикации из корня репозитория относительные пути в manifest и service worker сохраняют работоспособность и с адресом GitHub Pages в подпапке.

## Что важно знать

- Данные сохраняются локально в браузере конкретного устройства; общей синхронизации между устройствами или пользователями нет.
- В текущем приложении добавленные файлы представлены именем и размером; их содержимое не загружается и не сохраняется.
- Начальное фото объекта загружается с Unsplash. После посещения оно может кэшироваться браузером для офлайн-просмотра.
- После первой загрузки service worker кэширует оболочку приложения для последующей работы без сети.
